# Sample data

The smallest set of data a local reference deployment needs. It exists so that:

- the Decision API's input and output are pinned to concrete examples;
- the shape of a JSON policy and a policy bundle can be seen rather than inferred;
- the access log, the audit log and the decision trace have a first set of test data.
